# 长辈TV · 电视播放器

给老人用的安卓电视播放器。打开电视就直接接着放上次的剧，播放接在电视 USB 口上的移动硬盘里的电视剧。

- 包名：`com.ayou.elderplayer`
- 安卓 5.0 及以上都能装。APK 里带 32 位和 64 位 ARM 两套库，老电视大多是 32 位的。
- 播放用 Media3 ExoPlayer。视频只走电视的硬件解码（有硬解就不用谷歌自带的软解）；电视自己解不了的 AC3 / DTS 等音轨，交给 ffmpeg 扩展（NextLib）解码。
  - 视频不再用 ffmpeg 软解：老电视 CPU 弱，4K H265 软解一卡一卡的（TCL 上碰到过）。

## 下载

到 Releases 下载 APK，两个包签名一样，按电视选：

- `zhangbeitv-standard-release.apk`：一般的电视用；
- `zhangbeitv-nohome-release.apk`：TCL 这类不让第三方 App 声明桌面的电视用，装 standard 包报「证书不一致」时换这个。

装好以后怎么授权、怎么设成开机直接进，见下面的「装到电视上」。自己编译出来的包签名不一样，不能覆盖安装 Releases 里的包，要先卸载（进度会丢）。

## 硬盘里怎么放

最外层一部剧一个文件夹，文件夹名就是画面上显示的剧名。下面两种放法都认，可以混着用：

```
移动硬盘/
├── 某某电视剧（2026）/        ← 视频直接放在剧名文件夹里
│   ├── 第1集.mp4
│   ├── 第2集.mp4
│   └── 第10集.mp4
└── 另一部剧/                  ← 下面再分季
    ├── Season 1/
    │   ├── S01E01.mkv
    │   └── S01E02.mkv
    └── Season 2/
        └── S02E01.mkv
```

- **排序是固定的**，每次打开都一样：
  - 剧按文件夹名自然排序，第 2 排在第 10 前面。
  - 集数能认出这些写法：`S01E02`、`1x02`、`E02` / `EP02`、`第2集`、`第十二集`、`02集`、`02.mp4`，名字里夹着年份、分辨率、编码的也能认（比如 `某剧.2026.04.1080p.x264.mkv`）。
  - 同一个文件夹里，有一个文件认不出集数，整个文件夹就改按名称排，免得认错的文件打乱顺序。
- **季文件夹**认 `Season 1`、`S01`、`第一季`、`第2季`，按季数接起来。`Specials`、`番外`、`花絮` 这类特别篇放在最后。
- **外挂字幕**：和视频同名的 `.srt` / `.ass` / `.vtt` 会自动加载，比如 `第1集.srt`、`第1集.chs.ass`。字幕字号放大过。
- **会跳过的**：
  - 隐藏文件，以及 Mac 拷贝时留下的 `._` 文件；
  - `System Volume Information`、回收站；
  - 名字带 `sample` 的文件或文件夹。
- **支持的格式**：mkv、mp4、m4v、mov、ts、m2ts、avi、flv、webm、mpg。
  - rmvb、wmv 放不了。老剧是 rmvb 的话，先转成 mp4。

## 遥控器

| 按键 | 作用 |
|---|---|
| 上 / 下 | 换剧，到头了会循环。停手 0.8 秒后自动开始放，不用确认。连按可以一口气跳过几部 |
| 左 / 右 | 快退 / 快进：按一下 10 秒，1 秒内连按、或者按住不放，每次 20 秒 |
| 确认 | 暂停 / 继续。暂停时大字显示剧名、第几集和进度 |
| 返回、菜单 | 不会退出，只显示一下现在在放什么 |
| 主页 | 设成桌面以后，按主页键还是回到播放器 |

- 每部剧各自记住看到第几集、几分几秒。切到别的剧再切回来，从原来的地方接着放。
- 一集放完自动放下一集。
- 一部剧最后一集放完，自动接着放下一部剧；最后一部放完回到第一部，一直循环。
- 放完的那部剧会从第 1 集重新记，下次轮到它从头看。

## 放不了的片子

**怎么算「放不了」。** 每秒检查一次，满足下面任意一条就算：

- 播放器直接报错：格式不认识、文件坏了、解码器出错；
- 卡住不动：本该在放，进度却连续 20 秒没动，一直转圈缓冲也算。暂停的时间不算；
- 有画面轨道但电视解不了，结果黑屏只有声音。声音解不了、只有画面没声音的，也算；
- 画面冻住：进度在走，但 15 秒以上一帧画面都没出来。

**放不了以后怎么处理。**

- 跳到下一集，屏幕上提示「第 N 集 放不了，自动跳到下一集」。这一集会被记下来，以后轮到它直接跳过，不用再卡 20 秒。
- 同一部剧**连续 3 集**放不了，整部剧跳过，提示「《剧名》连续 3 集放不了，先跳过这部」，接着放下一部。
- 只要中间有一集正常放满 20 秒，连续次数就清零。
- 所有剧都被跳过时，屏幕提示请家人看一下。
- 安卓 5、6 上，如果是解码出错（电视硬解起不来、解不了），而且电视装了自带播放器（目前认 `com.tcl.videoplayer`），这一集交给自带播放器放，进度先记到下一集，按返回回来就接着放下一集。交出去的集不算「放不了」，下次轮到还会再交出去。

**家人怎么处理。** 维护页里会显示跳过了哪些剧、多少集，点「恢复跳过的剧和集」就全部放回来。比如把片子转码以后，就点它恢复。

## 家人维护页

进法：3 秒内连按 5 下菜单键（遥控器上画着「≡」的那个）。

确认键故意不做长按功能：长辈常常按住不松手，长按会误进维护页。

1 分钟不操作，会自动回去播放。

维护页能做的事：

- 选剧；
- 选集（改到第几集）；
- 重新扫描硬盘；
- 打开电视设置；
- 回到电视原来的桌面；
- 看现在用的解码器：「视频解码」后面写着名字和（硬解）/（软解）。4K H265 应该是 `OMX.amlogic.hevc…` 这类硬解，写着软解的话电视就扛不住；
- 看播放统计：今天、近 7 天各看了多久，以及最近几次看的是哪部剧、哪几集。统计只存在电视本机。

## 编译

需要 Android SDK（compileSdk 36）。播放库固定在 media3 1.8，这是最后一个支持安卓 5.0 的版本，别随手升级。另外还需要 JDK 17 以上。这台 Mac 上用的是 Android Studio 自带的 JDK：

```bash
export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"
```

```bash
./gradlew testStandardDebugUnitTest assembleRelease assembleDebug
```

会打出两种包，签名、包名都一样，可以互相覆盖安装，进度不会丢：

| 包 | 用在哪 |
|---|---|
| `app/build/outputs/apk/standard/release/zhangbeitv-standard-release.apk` | 一般的电视。带「当桌面」入口，默认关着，见下面第 3 步 |
| `app/build/outputs/apk/nohome/release/zhangbeitv-nohome-release.apk` | TCL 这类电视。没有「当桌面」入口，就是个普通 App |

有的 TCL 固件只让 TCL 自己签名的 App 声明成桌面，遇到别人的就拒装。报错写的是「证书不一致」，其实跟签名没关系，换 U 盘装也一样。这种电视装 nohome 包，开机由别的桌面（比如 Aerial）打开长辈TV，第 3 步跳过。

`debug` 目录下是能调试的版本，会把播放器事件打到 logcat，查问题时用。

## 装到电视上

**1. 打开电视的 ADB 调试。** 在电视设置里打开开发者选项和 USB / 网络调试，电脑和电视连同一个 Wi-Fi。老电视一般是在「关于」里连按几下版本号，开发者选项就出来了。

```bash
adb connect 电视的IP
```

```bash
adb install -r app/build/outputs/apk/standard/release/zhangbeitv-standard-release.apk
```

**2. 给读硬盘的权限。** 安卓 5.x 装好就有权限，这一步跳过。

安卓 5.x 上，App 同时声明了写存储权限（只在 5.x 上声明）。不少老电视把硬盘挂成只有 `sdcard_rw` 组能进的目录，只有读权限的话能看到硬盘，却打不开里面的文件夹，界面会显示「找到了硬盘，但里面没有剧」。

安卓 6～10：

```bash
adb shell pm grant com.ayou.elderplayer android.permission.READ_EXTERNAL_STORAGE
```

安卓 11 及以上：

```bash
adb shell appops set com.ayou.elderplayer MANAGE_EXTERNAL_STORAGE allow
```

不用电脑也行，第一次打开时会弹系统授权窗口，选「允许」。只是在安卓 11 及以上，这样只能读视频，外挂字幕读不到，所以还是建议用上面的命令。

**3. 设成开机直接进的桌面。**

如果电视上已经装了别的桌面（比如 Aerial），并且用它的「开机自动打开」来打开长辈TV，这一节整个跳过。

长辈TV 当桌面的入口默认是关着的。开着的话，别的桌面会把它当成原厂桌面赶走，看起来就像闪退一下。所以要先打开这个入口：

```bash
adb shell pm enable com.ayou.elderplayer/.HomeEntry
```

先查电视自带的桌面是哪个包：用遥控器按一下主页键，让电视停在自带桌面上，然后执行下面这条（各个安卓版本都能用）。

```bash
adb shell dumpsys window windows | grep mCurrentFocus
```

输出里 `/` 前面那段就是包名，小米电视一般是 `com.mitv.tvhome`。下面的命令里，把它换成你查到的包名，按顺序来。

1. 把播放器设成桌面，按安卓版本选一条：

   - 安卓 10 及以上：

     ```bash
     adb shell cmd role add-role-holder --user 0 android.app.role.HOME com.ayou.elderplayer
     ```

   - 安卓 7～9：

     ```bash
     adb shell cmd package set-home-activity --user 0 com.ayou.elderplayer/.HomeEntry
     ```

   - 安卓 5、6：没有这类命令，跳过，看第 2 步后面的说明。

2. 停用自带桌面：

   ```bash
   adb shell pm disable-user --user 0 com.mitv.tvhome
   ```

   安卓 5、6 停用以后，按一下遥控器主页键，可能会弹「选择桌面」。选「长辈TV」，再选「始终」。

3. **等 15 秒以上再重启电视。** 系统大约 10 秒后才把停用状态写到磁盘，马上重启这次设置就丢了（模拟器上就碰到了）。

   ```bash
   adb reboot
   ```

开机后，硬盘还没挂载好时，屏幕上显示「正在找移动硬盘…」。挂载好以后会自动开始放，不用动遥控器。

**想恢复原来的桌面：** 维护页的「回到电视原来的桌面」只在自带桌面还没停用时能直接跳过去。按上面停用以后，点它会弹窗提示恢复命令。要彻底恢复，执行：

```bash
adb shell pm enable com.mitv.tvhome
adb shell pm disable com.ayou.elderplayer/.HomeEntry
```

## 测试

`app/src/test/` 下有 55 个单元测试：

- 自然排序；
- 各种集数、季数写法的识别（包括 `S01E01.2026.2160p.WEB-DL.H265.AAC.mp4` 这种）；
- 两种文件夹结构，以及多季合并的顺序；
- 跳过垃圾文件；
- 认硬盘挂载点（`/mnt/usb/sda1` 这种两层的不会把 sda1 当成剧）；
- 每部剧的进度记忆：换剧、重开 App、加了文件、文件改名、停在片尾；
- 换剧循环；
- 快进步长；
- 选视频解码器（有硬解就不用软解）；
- 连按菜单键进维护页的计数；
- 播放统计；
- 判断放不了：卡住、画面冻住、暂停不算、快进不误判；
- 跳集和连续 3 集跳过整部剧的记录。

模拟器上测过三个版本：

- **Android TV 12**：完整流程都走过。
  - 用 `sm set-virtual-disk true` 模拟插 U 盘，挂载广播会正常触发；
  - 授权、找硬盘、播放、暂停、快进；
  - 换剧后回来接着看；
  - 一部剧放完接下一部；
  - 外挂字幕；
  - 拔盘再插回来，从原位置接着放；
  - 返回键不退出；
  - 连按菜单键进维护页、选剧；
  - 设成桌面以后重启，开机直接放；
  - 放了坏文件：一部剧 4 集全坏，坏了 3 集后整部剧跳过；好剧中间夹一集坏的，跳过它接着放；维护页能恢复。
- **安卓 8.0**：
  - 硬盘模拟成老电视的 `/mnt/usb/sda1`，能认出来；
  - 播放、换剧后接着看、外挂字幕都正常；
  - 用 `set-home-activity` 设成桌面后重启，开机直接放。
- **安卓 5.0**：
  - App 能装、能打开，能认出 `/mnt/usb/sda1` 里的剧；
  - 模拟器自己解不了这个视频，自动改用 ffmpeg 解码，画面出来了；
  - 但这台模拟器的声音输出不工作，播放器的时钟靠声音走，所以进度一直停在 0。这是模拟器的问题，真电视上要实际看一下；
  - 正好拿它测了「卡住不动」：每集 20 秒后自动跳过，连续 3 集以后整部剧跳过。
